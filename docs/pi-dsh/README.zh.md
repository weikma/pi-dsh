# Pi DSH

[English](README.md) | 中文

## 摘要

Pi DSH 为官方 Pi Coding Agent（编程智能体）提供桌面和本地 Web 工作区，支持原生包管理、会话历史及项目工具。Electron 与本地 Web 共用一个 React 界面和一个回环地址宿主。Pi 通过[公共 RPC](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/rpc.md)作为独立子进程运行；它管理 agent loop（智能体循环）、工具、模型上下文、认证、资源、设置和原生会话。

## 配置工作副本

使用 Node.js 22.x 系列中的 22.19 或更高版本，或 Node.js 24 及更高版本，并使用仓库声明的 pnpm 版本。Pi 安装器还需要 npm 和官方 npm registry 的访问权限。它将所选官方版本与 GUI 的依赖分开安装。

```sh
pnpm install
pnpm pi:install 0.99.1
pnpm pi --version
```

在任一 GUI 中打开 **设置 → 模型与服务商**，使用 Pi 已有服务商配置、填写 API 密钥，或按 Pi 可用的 OAuth 方法登录。官方 Pi CLI（`pnpm pi`）仍可配置资源和不支持的登录方式。服务商要求参见 [Pi 文档](https://github.com/earendil-works/pi/tree/main/packages/coding-agent)。GUI 认证调用 Pi 公共 SDK，凭据由 Pi 自身的认证存储写入。

展开服务商可查看模型名称和 ID、搜索较长列表，并选择可用模型。数量表示 Pi 已登记的模型，并非远端服务提供的全部模型。打开对话后，优先显示该对话的公共模型列表，包括已加载扩展提供的模型。仅通过 `models.json` 配置的兼容端点使用明确登记的模型列表；打开设置页不会探查远端模型。

选择任一开发界面；两者使用同一个应用：

```sh
pnpm dev:web
```

```sh
pnpm dev:desktop
```

开发版 Web 界面位于 `http://127.0.0.1:5174`。其 API 代理连接本地宿主。使用构建后的资源时，先运行构建，再选择一个入口：

```sh
pnpm build
pnpm start:web
```

```sh
pnpm start:desktop
```

构建后的 Web 宿主输出其回环 URL；默认端口为 `19388`。`PI_DSH_PORT` 更改 Web 宿主端口。Desktop 在可用端口启动应用自己的宿主，并在文件菜单中提供**在浏览器中打开**。原生安装包在 ASAR 外携带官方 Pi CLI 和独立 Node／Python 资源，无需系统安装 Node 或 Pi 即可运行。供应商认证及访问仍遵循 Pi 的配置。

<a id="usage"></a>
## 使用 GUI

选择项目、打开会话或配置服务商之前即可输入。未选择项目时，**发送**会打开 Desktop 的文件夹选择器或 Web 的文件夹浏览器，并在选择项目过程中保留草稿。**新建对话**、项目行按钮、Command／Ctrl+N 和 `/new` 都打开空白输入框，不添加侧栏条目，也不启动 Pi。每次新建操作会清空该草稿中未发送的文字和附件。发送首条消息后启动 Pi 并刷新原生历史列表，先立即以首条用户消息作为临时标题，随后使用原生会话名称。可从各项目分组选择现有 Pi 原生会话并恢复。切换对话时，未发送的草稿及图片按对话保留在内存中，直到此 GUI 关闭或刷新；点击当前对话不会清除草稿。

首轮完整回复成功结束后（包括工具执行和排队输入），当前模型会发起一次独立的后台请求，把首条消息概括为短标题，目标约为十个中文字符或五个词。侧栏随后用这个模型摘要替换首条消息临时标题，Pi 会保存该名称供再次打开时使用。手动改名优先；生成失败时保留首条消息标题，仅打开旧对话不会触发标题生成。

新对话页将 Pi 图标、标题和输入框作为整体居中。项目条支持搜索已注册文件夹、打开文件夹和清空选择，并保留草稿；清空状态在重启后仍然有效。Git 仓库还会显示本地分支搜索、未提交文件数、分支切换、从当前 HEAD 创建分支，以及可查看提交详情的分页历史图。Git 保留本地更改，并拒绝覆盖更改、冲突、进行中的 Git 操作和已被其他工作树占用的分支。仓库内的 Pi 任务、排队输入和对话框处理完成后才能切换分支。历史图只读取已有的本地、标签和远程引用，不拉取远程数据。Desktop 和 Web 共享这些控件。

提交消息后立即显示消息，Pi 在后台启动。进度标题在一秒后首次显示为**正在处理 1s**；收到 Pi 原生消息后替换本地气泡，不显示发送回执。启动或发送失败时恢复未发送的文字和图片，保留期间继续输入的内容。启动完成前切换对话，会阻止该请求发送到其他对话。扩展提问替换底部输入框，对话区仍可阅读和滚动。用鼠标或方向键选择，再点击**提交**或按 Enter。进入已识别的**自由回答**行会选择该原生选项，并将后续匹配的文本问题保留在同一行；Enter 提交，Shift+Enter 换行。其他扩展保留原生请求顺序。原始选项字符串和取消行为仍由 Pi 管理。OpenAI 推理摘要与其他模型共用“思考”展示。展开处理过程即可直接阅读思考内容，各思考区域仍可单独收起。已完成的空思考块会提示未收到可展示的文本。思考正文仅在显示时移除开头的 `Thinking:` 标签和终端颜色码；通用扩展输出也移除终端颜色码。原生记录及复制的消息原文保持不变。

Web 的**添加项目**可浏览 Host 文件夹、筛选名称、按需显示以点开头的文件夹，并创建子文件夹，也可直接输入绝对路径。Desktop 保留原生目录选择器；两种方式都保留对话草稿。

打开已保存的对话时，先读取原生记录，Pi 在后台恢复。恢复期间可以阅读、复制和起草回复；发送和修改历史的操作在 Pi 就绪后启用。启动失败时保留可读记录。不支持的原生记录版本交由 Pi 加载和迁移。

点击项目名称可展开或收起其对话。悬停或键盘聚焦会显示项目及对话操作：新建对话、项目重命名／移除、对话置顶、重命名、分叉和归档。搜索在项目标题行内展开，Escape 关闭；**显示选项 → 已归档对话**提供恢复入口。项目别名、折叠、置顶及归档状态属于 Desktop 偏好；移除项目仍保留其文件夹和 Pi 原生会话。对话重命名和分叉使用 Pi 公共 RPC。
macOS Dock 角标显示已有回复结束、尚未查看的对话数，每个对话最多计一次。Desktop 和 Web 侧栏为这些对话显示未读圆点。只有对应原生回复条目显示在可见且获得焦点的对话中，才会标为已读；打开其他对话或设置不会清除它。Pi 完成工具调用、重试和排队输入后，回复才计入统计。停止回复、重新打开历史和切换分支不会产生完成提醒。已读状态由 Desktop 元数据保存，重启应用后保留；已归档的对话及已移除项目不计入角标。

聊天框的 **+** 在输入框上方打开文件引用、图片附件及同一组精选斜杠命令。可浏览或筛选项目目录，或输入目录路径；选择文件后在光标处插入可见的 `@路径` 并保留草稿，含空格的路径使用引号。Pi 原样接收文本并决定何时读取文件；Desktop 不注入文件内容。模型左侧的小圆环在第一轮完整回复结束后显示。后续流式输出和工具执行期间，占用、内容占比及缓存命中率保持上一轮完成时的值，下一轮完整回复结束后再更新。悬停或键盘聚焦可查看估计，所有界面语言均以 `K`/`M` 简写 token 数量和容量。悬浮信息卡显示系统提示词、Pi 工具、直接声明的 MCP 工具、扩展工具、技能、消息和工具结果的估算占比，隐藏空分类。占比按各分类的字符数归一化，并从大到小排列。分隔线下的 **缓存命中率** 使用会话累计缓存输入量除以总输入 token 数；尚无有效用量时显示短横线。压缩后未知的占用保持未知，直到 Pi 返回新的估计。请先在 **设置 → 模型与服务商** 中配置服务商；聊天框只选择已配置的模型。


打开 **设置 → 模型与服务商**即可读取 Pi 原生配置，无需选择项目或启动对话。已配置服务商优先显示；**添加服务商**可搜索其余目录。API 密钥输入框使用密码类型，不回显已保存密钥。Pi OAuth 回调可以请求浏览器链接、设备代码、文本、选项或手动代码；面板提供打开／复制链接、取消和重试。界面只显示所选 Pi 服务商提供的认证方法。

**添加兼容服务商**将非秘密的端点、API 协议和模型字段存入 Pi 的 `models.json`，保留其他服务商和未编辑字段，再启动 Pi 的 API 密钥提示。**模型**先列出服务商及其模型数量，再搜索所选服务商的模型，也可返回服务商列表。搜索还支持跨服务商匹配模型名称和 ID，并显示所属服务商及原生 ID。打开对话前，明确选择的模型会保留，并在打开对话时通过公共 `set_model` 应用。新对话继承最近使用的模型和 thinking level，切换项目或重启应用后仍然保留。Desktop 将选择存入 GUI 偏好，并在首条消息前通过 Pi 公共命令应用。已有对话保留原生模型及 thinking level；记住的模型不可用时，会在发送前报告错误。

配置服务商后，空闲对话重连以读取 Pi 更新后的凭据和模型，同时保留已保存的原生历史与 GUI 草稿。执行、压缩、排队输入或扩展弹窗会延后重连；完成或清除这些工作后，再点击**刷新模型**。配置变更不会中止正在进行的任务。

扩展注册的服务商、包装可执行文件、编译型 Pi 运行时，以及缺失或不兼容的公共 SDK 导出，应使用 Desktop 的**打开 Pi 终端**或 Web 的**复制 Pi 启动命令**。私有启动脚本保留所选运行时的环境，不显示密钥，仅在当前 Host 和运行时选择有效期间可用。对话 RPC 仍会加载 Pi 扩展；仅限 TUI 的配置仍在 Pi 终端中完成；GUI 登录快捷命令不会成为模型提示。

对话记录显示 Pi 的文本、思考、图片、工具活动及可展开的原生压缩／分支摘要。每次回复的思考、中间回复和工具统一放在带分隔线的**正在处理 …**折叠区内。第一秒内不显示进度标题，随后每秒更新耗时。使用原生开始时间戳；本地启动更早时，从本地启动时间开始计时。运行时默认展开，完成后自动收起，标题原地变为**已处理 6h 20m 5s**，最终回复始终显示在折叠区外。所有语言统一使用 `h`、`m`、`s`。完成耗时根据原生用户消息和持久化回复的时间戳计算；缺少时间信息的记录显示**处理完成**。停止或失败的回复保留相应状态和部分正文。消息操作在悬停或键盘聚焦时出现，最新回复始终显示操作。复制和分支按钮紧凑排列，其后显示原生消息的本地时间，采用 24 小时制 `HH:mm` 格式；缺少时间戳时不显示时间。提示框与按钮保持间距，并在对话滚动时关闭。**复制消息**复制消息原文；向上滚动后，**回到最新消息**恢复跟随最新回复。取消后的部分回复仍可见，不显示失败通知。Bash 使用保留的终端卡片；陌生工具以通用方式显示参数和输出。工具中的文件路径打开只读预览。文件面板无需打开对话即可浏览已注册项目，支持文件夹原地展开和目录筛选，可预览源文件、PNG／JPEG／GIF／WebP 图片、XLSX／CSV／TSV 工作表及 DOCX／PPTX 文档内容。工作表标签和网格保留数据及公式文本，不重新计算；文档内容显示在沙箱 frame 中。这些预览不确认打印布局。没有旧 DOC／XLS／PPT 格式及 PDF 预览；不支持预览的文件仍可原生打开或从 Web 下载。对话公式使用保留的 Markdown／KaTeX 渲染器。

在 Desktop 或 Web 对话中输入 `/`，查看当前可用的日常入口：模型、思考深度、压缩、分叉、会话信息和 Pi 历史。打开对话前只显示模型选择；会话忙碌或缺少历史能力时进一步减少列表。分组菜单与输入框等宽，显示图标、本地化名称和右对齐说明。可按命令名、本地化标题或说明关键词查找其他 GUI 入口、Pi 命令、提示模板和技能。方向键浏览时焦点保留在输入框；Enter 或点击打开 GUI 操作，Tab 只补全文本。选择原生资源时补全其精确调用名称；对已完整输入的原生命令按 Enter 会提交给 Pi。Escape 或点击外部关闭菜单且不修改草稿。同名 Pi 注册命令优先。以下入口调用 Pi 公开操作或现有 GUI 控件，本身不会启动模型请求；`/compact` 例外，会使用 Pi 的压缩模型。

| 命令 | Desktop 和 Web 行为 |
|---|---|
| `/model [服务商/模型ID]` | 打开模型选择，或选择已配置服务商的精确模型 ID。 |
| `/thinking [深度]` | 打开思考深度选择，或设置当前 Pi 模型支持的深度。 |
| `/new` | 新建对话，必要时先选择项目。 |
| `/resume` | 打开侧栏中的已保存对话搜索。 |
| `/name [文字]` | 打开重命名，或设置原生会话名称。 |
| `/session` | 显示 Pi 原生会话文件、ID、消息和工具次数、token、费用及上下文用量。 |
| `/tree` | 打开原生会话树。 |
| `/fork` | 选择一条用户消息，分叉为独立原生会话。 |
| `/clone` | 让 Pi 从当前位置克隆当前会话。 |
| `/compact [要求]` | 从菜单选择压缩后先填写可选要求，再启动 Pi 压缩；停止按钮可取消等待中的请求。直接输入带参数的命令会原样传递要求。 |
| `/copy` | 复制 Pi 返回的最新助手文本。 |
| `/export [路径]` | 通过 Pi 导出 HTML，并显示文件路径。 |
| `/login`、`/logout` | 打开服务商认证操作。 |
| `/settings` | 打开按类别组织的 GUI 设置工作区。 |

切换历史或压缩前，先完成执行、排队输入和 Pi 弹窗。参数无效或操作失败时保留命令，以便修改或重试。JSONL 导出以及 `/reload`、`/hotkeys` 等已知仅限 TUI 的命令会显示原生终端配置入口；Desktop 提供**打开 Pi 终端**，Web 提供**复制 Pi 启动命令**。这些命令不会作为模型提示词发送。未知资源命令仍原样传给 Pi。

Desktop 和本地 Web 共享**在编辑器中打开**及**文件操作**，支持选择已安装编辑器、使用默认应用、在文件管理器中显示、复制路径和下载。Desktop 还提供原生应用选择器。**项目文件 → 打开方式…**可在 Host 电脑的已安装编辑器、终端或文件管理器中打开项目。SSH 和无桌面环境的 Host 隐藏本机应用操作。Host 校验项目路径并使用字面参数启动应用；GUI 自己的 `PI_DSH_HOME/editor.json` 记住所选编辑器。

右侧工作区面板初次打开时提供**项目文件**、**终端**和**浏览器**，**+** 打开新的选择页。关闭最后一个标签会收起面板，再次打开时回到这三个入口。文件区显示只读根路径、圆角搜索框和刷新按钮；文件夹在原地展开，文件各自打开预览标签。切换对话或收起面板时，标签、目录展开状态、搜索及运行中的终端／浏览器内容按项目保留，直到 GUI 关闭或重新加载。终端在已登记的项目目录启动本地 shell；关闭标签会停止该 shell 及其子进程。Desktop 浏览器提供隔离的网页标签，支持地址、后退、前进和刷新。输入地址后点击**前往**或按 Enter；**在浏览器打开**位于页面下方。Web 使用沙箱嵌入网页，其前进／后退控制覆盖地址栏输入过的地址；禁止嵌入的网站可在外部浏览器打开。

macOS 用 **Command+B** 切换对话历史侧栏，Windows／Linux 用 **Ctrl+B**。右侧文件面板分别用 **Command+Option+B** 和 **Ctrl+Alt+B** 切换。快捷键保留草稿，忽略正在进行的输入法组字；模态弹窗保留键盘焦点。

Pi 运行期间，选择**引导**或**排队**并按 Enter，使用 Pi 对应的队列语义。执行或压缩期间，输入框的**发送**按钮原地变为**停止**，Pi 停止后恢复为**发送**。点击**停止**，或在未打开菜单和对话框时按 Esc，请求 Pi 取消并保留草稿。**清空队列**清除 Pi 的待处理输入。每条已完成的用户或 AI 消息都提供**从此处继续**，在同一个原生会话内导航，或**分叉对话**，创建包含该节点的新原生会话。**会话分支**可搜索完整树，包括中间 AI 工具调用消息、其他分支及摘要。Pi 保留原有分支；导航不启动模型请求，也不生成摘要。修改历史前应完成执行、排队输入及弹窗；公共历史扩展不可用时禁用相关操作。重命名和压缩使用公共 RPC；历史操作使用 Pi 公共扩展命令上下文。扩展对话框支持公共 confirm、select、input 和 editor 请求；状态及文本组件更新显示在对话记录中。

设置按通用、外观、模型、Agent、指令、技能、命令、MCP、扩展、快捷键和运行时分类，资源列表支持搜索。`/settings` 打开同一 GUI。语言和外观立即生效，保存时保留运行时选择。更改运行时会停止现有桥接进程，并清除其 GUI 活跃句柄。保存后重新打开原生会话。**使用内置 Pi**恢复发行版默认运行时，不固定当前安装路径。已保存的对话仍由 Pi 管理。

**设置 → 外观**分别控制界面文字（12–20 px）与代码文字（10–24 px）的大小。Markdown 代码块和源文件预览支持独立的浅色/深色代码主题、行号及长行自动换行；共享差异视图使用相同的显示偏好。修改后立即生效，重启后仍然保留。调整界面字号保持图标和面板尺寸不变，复制代码不包含行号。这些 GUI 偏好不会修改 Pi 运行时选择和原生设置。

<a id="runtime"></a>
## 配置运行时

工作副本安装器写入被忽略的 `apps/pi-dsh/runtime/selected.json`，并在 `apps/pi-dsh/.pi-runtime/<version>/` 下创建隔离的 npm 安装。它记录官方包版本、registry 完整性值和源代码修订，并验证已安装 CLI 的版本。所选 `command` 是安装器使用的独立 Node 可执行文件；`args` 以官方 Pi CLI 入口开始。Pi 不在 Electron 的 Node 运行时内执行。

打包后的 Desktop 将运行时选择保存为 Electron 用户数据目录中的 `runtime.json`。`PI_DSH_RUNTIME_CONFIG` 可为任一界面选择显式配置文件。已有选择优先，其次为明确提供的 `PI_EXECUTABLE`，再其次为随包发行版。Desktop 不会隐式从 PATH 查找 `pi`。源码启动缺少选择和随包资源时，会提示运行 `pnpm pi:install` 或 `pnpm runtime:prepare`。`{ "mode": "bundled" }` 选择跟随当前发行版默认运行时，包括 Desktop 升级后。随包默认运行时使用自己的 Node 可执行文件，不使用 Electron 的 Node 模式。外部 Windows 运行时应选择 Node，并在 `args` 中填写官方 Pi CLI JavaScript 入口；`pnpm pi:install` 会生成此配置。全局 npm 的 `pi.cmd` 包装脚本不是无 shell 启动直接支持的可执行文件。参见[运行时选择升级指南](../upgrade-guide/v0.2.0-rc.4/runtime-selection/guide.zh.md)。 旧版本的名称与默认配置迁移见[命名升级指南](../upgrade-guide/v0.2.0-rc.58/product-name/guide.zh.md).

Agent 设置通过所选官方 Pi SDK 保存用户默认值：模型／服务商、思考深度、自动压缩与重试、图片缩放／禁用、技能命令及引导／后续消息投递。已信任的项目设置和显式 CLI 选项优先。新对话读取已保存值；**重新加载当前对话**为闲置原生会话应用配置并保留历史，已有会话的模型选择仍由 Pi 管理。

技能和命令按用户／项目范围列出原生资源，支持搜索、新建、Markdown 编辑和启停。指令展示 Pi 发现的上下文文件，上级目录文件只读。包内资源可以查看，但其源文件保持只读。未保存的编辑需要明确放弃；文件版本已过期时，保存失败且不覆盖外部修改。发现资源使用公共包解析 API，不加载扩展代码或安装缺失的包。项目资源遵循 Pi 保存的信任状态，明确的信任操作通过公共 ProjectTrustStore 写入。

MCP 设置向 Pi 文档规定的 `mcp.json` 添加 stdio／HTTP 条目，并修改启停状态或工具可见方式。修改保留其他字段、认证引用和符号链接目标，凭据值不返回 GUI。已配置不代表已连接。原生 `/mcp` 管理连接状态、工具、重新连接和 OAuth；接管 `/mcp` 的扩展继续使用自己的配置。侧栏的 **扩展** 和 **技能** 打开[包中心](extensions.zh.md#marketplace)，支持官方市场搜索、固定版本安装、更新、移除和原生资源过滤。扩展特有的终端设置仍可在 Desktop 中打开，Web 提供复制启动命令。

Pi 默认使用 `~/.pi/agent`，与已有终端安装共用。`PI_CODING_AGENT_DIR` 可覆盖此目录；运行时 `env` 覆盖继承环境，显式 `agentDir` 又优先于两者。面板显示实际目录，Desktop 默认不创建独立凭据配置。POSIX Desktop 在后台读取登录 shell 环境，启动 Pi／服务商进程前应用；项目设置遵循所选配置上下文。GUI、草稿、项目导航和普通文件预览不等待此读取。

随包发行版目前锁定 Node `24.21.0`、官方 Pi `0.99.1`、pnpm `11.7.0`、Python `3.12.14`、13 个 Python distribution、ripgrep `15.2.0` 和 fd `10.3.0`。首次使用在后台将完整资源离线复制到 `PI_DSH_HOME/runtimes/pi-<version>-<target>-<manifest-hash>`；后续启动复用该不可变安装。Desktop 直接打开主界面，不再显示独立的“Preparing local runtime”窗口。需要 Pi 或 Office 工具的请求等待准备完成，错误通过正常 API／UI 路径显示。退出中止并等待 shell 探测，且等待运行时原子发布。它保留 Pi 独立的凭据和原生会话存储。`PI_DSH_BUNDLED_RUNTIME` 为源码或测试启动选择已准备的资源。

公共 Pi 扩展注册 `load_workspace_dependencies`，返回 Node、Python、pnpm、库及 Office 检查脚本的绝对路径，并通过 Pi 资源 API 发现三个 Office skill。Pi 自己记录工具结果；Host 不添加隐藏模型上下文。Python 包含 numpy、pandas、python-docx、python-pptx、openpyxl、Pillow、lxml、XlsxWriter 及其锁定依赖。[辅助资源说明](../../apps/pi-dsh/runtime/AUXILIARY.zh.md)介绍组装和结构检查限制。

| 字段 | 含义 |
|---|---|
| `mode` | `bundled` 恢复当前内置默认版本；选择外部命令时省略。 |
| `command` | 不经 shell 启动的外部可执行文件。 |
| `args` | 桥接层添加 Pi RPC 和会话选项之前的 JSON 参数数组。 |
| `env` | 外部 Pi 进程的可选环境覆盖值。 |
| `agentDir` | 可选的 Pi agent 目录，以 `PI_CODING_AGENT_DIR` 转发。 |
| `version` | 可选的已记录版本标签；可执行文件兼容性仍需验证。 |

GUI 保留它没有编辑的环境覆盖值。按照 Pi 已公开的接口配置其 CLI 选项和资源。缺失的可执行文件、被拒绝的 RPC 命令、供应商错误或进程意外退出会显示为应用错误。

<a id="ownership"></a>
## 数据归属和限制

Pi 写入原生会话 JSONL，并维护凭据、设置和资源。桥接层通过公共 RPC 执行任务和修改会话。服务商登录／退出调用所选官方公共 ModelRuntime SDK 及其认证存储，Desktop 不实现第二份凭据存储。兼容服务商编辑只修改非秘密的 `models.json` 字段，并保留未编辑字段。密码响应仅临时传递，不保存到浏览器存储、对话记录或 GUI 偏好中。

宿主将项目、外观、语言、所选项目和原生会话导航存入 `PI_DSH_HOME/preferences.json`，`PI_DSH_HOME` 默认为 `~/.pi-dsh`。GUI 在保存更改前先读取这些偏好；localStorage 用作兼容缓存。Desktop 和本地 Web 的宿主使用相同主目录时共享偏好。此 GUI 不导入旧 DSH 会话。

侧栏从 Pi 配置的 `--session-dir` 或 `PI_CODING_AGENT_SESSION_DIR` 发现会话，未配置时使用所选 agent 目录的 `sessions` 树。GUI 不提供任意基于终端的扩展渲染器。DSH 权限预设、目标、后台任务、计划任务、工作流、账户计费、SDK 和插件管理控件均不存在。应用没有自动 Desktop 更新服务；运行时选择支持独立升级 Pi。

打包配置声明了 macOS arm64/x64、Windows x64 和 Linux 构建目标。声明目标不能确认该平台的安装器、签名或运行时验证；请单独记录这些检查。现有 DSH 用户应阅读[升级指南](../upgrade-guide/v0.2.0-rc.2/pi-dsh/guide.zh.md)。

## 升级 Pi

定位当前运行时配置、[桥接版本记录](../../apps/pi-dsh/bridge/version.json)和[兼容性检查](../../apps/pi-dsh/runtime/compat.ts)。通过公共 RPC、导出的认证 SDK、CLI／资源行为及原生会话格式比较所选与目标官方版本。RPC 兼容不能确认认证 SDK 兼容。GUI 功能与 Pi 冲突时，以 Pi 为准，适配桥接层或保留原生配置入口。

在工作副本中，用 `pnpm pi:install <version>` 选择精确版本；省略版本时选择 registry 当前的 `latest`。使用其他配置文件时，选择对应可执行文件，并在运行检查时设置 `PI_DSH_RUNTIME_CONFIG`。此外部选择覆盖随包默认版本，可不重建 Electron 而升级 Pi。更改运行时选择后重启宿主。更新发行版默认版本还需要更新 artifact／production 锁并准备目标平台；GUI 安装包携带此锁定资源。

```sh
pnpm test:compat
pnpm typecheck
pnpm test
pnpm build
pnpm test:docs
```

<a id="implementation"></a>
## 实现

共享客户端发送 HTTP 命令，并通过 Server-Sent Events 接收完整桥接状态。Host 为每个打开的对话启动官方 Pi RPC 进程。独立 Node worker 仅动态导入所选官方包的公共 SDK 导出，用于服务商目录和认证。worker 文件及 Pi 生产依赖位于 Electron ASAR 外的真实路径；Electron 与 React 消费不含秘密的桥接记录，不导入 Pi SDK 类。桥接层管理分帧、响应、进程关闭与版本适配。

保留的 React 基础组件、停靠组件、可观察存储、品牌类型、代码语言映射及路径工具不包含 Harness 执行逻辑。Electron 提供隔离的原生目录／应用选择器及外部链接控件；文件打开操作使用共享 Host。构建后的 `pi-session-controls.mjs` 作为真实资源位于 ASAR 外，仅用 Pi 公共扩展 API 导航原生会话树和从任意节点分叉。[应用源代码](../../apps/pi-dsh/)管理组合后的 GUI、宿主、运行时安装器和平台打包。

拖动任一侧栏与对话区的边界即可调整宽度；历史侧栏最小为 264px，工作区面板最小为 240px。宽度保存在 GUI 偏好中，折叠后仍保留，窗口缩小时会适配可用空间而不覆盖保存值。项目分组使用 300 毫秒的高度和透明度过渡展开或收起。侧栏和文件浏览器的快捷键与切换按钮使用 200 毫秒的宽度和透明度过渡，对话区随可用宽度平滑调整；窄窗口中的文件浏览器滑入并覆盖对话区。关闭文件浏览器会保留当前预览、筛选条件和滚动位置。拖拽时直接跟随鼠标，不使用过渡；分隔条获得焦点后可用方向键调整，Escape 可取消拖拽。隐藏的面板不接受鼠标或键盘输入；系统的减少动态效果设置会禁用这些过渡。

在原生 macOS 中，折叠侧栏会移除窄栏，并将导航控件保留在红黄绿窗口按钮旁；全屏时移除窗口按钮的避让空间。隐藏导航时，对话和预览仍占用明确的网格列；窄窗口预览以整个框架定位覆盖层。原生 Windows 在导航、对话和文件预览上方保留独立的 40px 标题栏，并为覆盖层提供对应边距；全屏时清除该标题栏空间。[窗口框架测试](../../apps/pi-dsh/tests/window-frame.test.ts)检查源码中的位置／避让规则和 macOS 拖动区域重收集；DOM 测试不能确认原生布局。普通 Web 保留紧凑的侧栏窄栏。

POSIX Desktop 每次启动在后台读取一次用户的交互式登录 shell 环境。完成环境输出、取消或失败后，它关闭探测的 stdout，仅停止探测自己的进程组，并等待直接 shell 子进程退出。它不修改 shell 配置文件，也不持久化环境。[登录 shell 测试](../../apps/pi-dsh/tests/login-shell-environment.test.ts)检查读取方进程自然退出，以及终止继承 stdout 的探测后台监听进程。
