# Pi DSH naming and attribution

English | [中文](BRAND_GUIDELINES.zh.md)

Use **Pi DSH** as the formal project and application name. Use **pi-dsh** for filenames, directories and repository slugs, **PI_DSH_** for environment variables, and **piDsh** where JavaScript identifiers require camel case.

Historical names appear only in the settings importer, its tests and the naming upgrade guide. `pnpm test:names` checks source paths and content while allowing those explicit migration references.

Pi DSH is an independent community project. Describe its use of Pi and DeepSeek Harness components accurately; do not imply that either upstream project officially maintains or endorses it.

Keep upstream copyright notices and licenses when redistributing derived code or assets. [Third-party notices](THIRD_PARTY_NOTICES.md) and the [asset documentation](apps/pi-dsh/assets/README.md) record their origins and license files.
